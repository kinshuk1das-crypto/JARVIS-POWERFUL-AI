JARVIS AI Setup Guide
Follow these steps to run your JARVIS AI Flask project.
1.	Install Python on your computer.
2.	Open VS Code or any Python editor.
3.	Create a new file named Jarvis.py.
4.	Paste your full JARVIS AI code into Jarvis.py.
5.	Open Terminal or Command Prompt.
6.	Install Flask using: pip install flask
7.	Run the project using: python Jarvis.py
8.	Open the browser link shown in the terminal.
9.	Use the AI chat, voice assistant, and website buttons.
10.	Customize your AI design, colors, and features anytime.
